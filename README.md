# Curbs (Krawężniki) — Godot rewrite

![Handwritten](https://img.shields.io/badge/provenance-handwritten-brightgreen)

*2022: original git history*

A full rewrite of [Curbs](https://github.com/nieczuje/curbs-gdevelop), the street-ball game originally built in GDevelop, done from scratch in Godot. Built as a learning project to compare the two engines (this Godot build was never released).

> Co-developed with [Ravenyy](https://github.com/Ravenyy) — forked from [his original repo](https://github.com/Ravenyy/Godot-Curbs) to keep the real collaborative commit history intact.

## About

The original GDevelop version was the one actually submitted to Google Play (Feb 2022); this Godot rewrite followed as a side project and was never published. Mechanically and visually it plays almost identically to the original — same rules, same look — since the point was comparing engines, not redesigning the game. See [curbs-gdevelop](https://github.com/nieczuje/curbs-gdevelop) for screenshots and gameplay video, since they'd look effectively the same here.
